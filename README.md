# Retail Executive Dashboard

**Technologies:** Power BI · SQL Server Express · SQL SMS 22 · DAX · Power Query (M)  
**Databases:** AdventureWorksOLTP25 & AdventureWorksDW25  

---

## Description

This repository showcases my Power BI dashboard, designed specifically for retail executives. It utilises the AdventureWorksOLTP25 and AdventureWorksDW25 databases, hosted on SQL Server Express and managed via SSMS 22. Connecting these databases directly to Power BI enables dynamic, real-time data visualisation straight from the database server.

## Dashboard Key Features

- New DAX measures and slicers to display sales and delivery performance KPIs.
- Dynamic chart titles that update automatically based on the selected KPI.
- Dynamic summaries that reflect insights based on active slicers.
- Drill-through functionality enabling executives to analyse specific product order details.
- Hover tooltips to preview drill-through pages before navigating.
- Reset button to clear all selected slicers with a single click.
